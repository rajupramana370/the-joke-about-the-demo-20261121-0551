A program that writes one one-line joke about working beside an AI coding
agent. The joke it writes:

> I told my AI agent to make the demo impossible to crash. It worked — now
> the app crashes at startup, before anyone can demo it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# -> out/entry.txt (the joke, UTF-8, well under 280 characters)
```

Deterministic, no network, Python 3 standard library only.
